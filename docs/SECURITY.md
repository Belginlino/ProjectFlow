# Security and Privacy

## Principles
Least privilege, role-based access, secure defaults, auditability and data minimization.

## Authorization
For every protected resource check:
1. authenticated user
2. institution boundary
3. project membership/role
4. action permission

## Files
Validate type/size, use non-guessable keys, scan where available, use signed URLs and never execute uploads.

## Secrets
Use environment/secret management. Never commit keys.

## Audit
Audit evaluation changes, evidence verification, rubric changes, role changes, archive/delete actions, AI approvals and outcome mappings.

## Privacy
Collect only data necessary for the workflow. Do not expose private student data to other students.

## Integrations
Use OAuth where available and request minimum scopes.

## AI privacy
Only send academic evidence to AI providers when institution policy permits it and provider retention is acceptable.
