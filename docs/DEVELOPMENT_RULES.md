# Development Rules

## Product
1. Evidence is a first-class entity.
2. Important evaluation claims must be traceable.
3. Automated alerts must have explanations.
4. AI output must be grounded in evidence.
5. Humans approve consequential academic decisions.
6. Task count is not a contribution score.
7. No student leaderboards.
8. Academic mappings are configurable.
9. Preserve audit history.
10. Integrate existing tools instead of rebuilding them.

## Engineering
- TypeScript strict mode.
- Python type hints.
- API versioning.
- Database migrations.
- Tests for core rules.
- Consistent errors.
- Secure environment configuration.
- Accessible components.
- No hardcoded secrets.
- No direct database access from frontend.

## Definition of Done
Functionality + authorization + validation + error handling + accessibility + tests + audit behavior + documentation.
