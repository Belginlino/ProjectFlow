# Hackathon Demo

## Scenario
Four students build an AI Attendance System.

### 1. Project
Create project, requirements, tasks and milestone.

### 2. Evidence
Student completes Face Recognition Model and uploads PR, model output and test result.

### 3. Mentor feedback
Mentor says accuracy is below expected threshold.

### 4. Change request
ProjectFlow creates a suggested change request.

### 5. Revision
Student submits revised model and test evidence. Mentor verifies.

### 6. Health
System flags missing testing evidence for two requirements and explains why.

### 7. Contribution
Show one student's verified evidence timeline.

### 8. Viva
Generate a question from the student's actual ML evidence.

### 9. Evaluation
Evaluator enters a score and clicks “Why this score?” to inspect the evidence chain.

## Closing line
> Existing platforms help teams manage work. ProjectFlow makes the evidence behind that work connected, verifiable and usable for contribution, learning and evaluation.
