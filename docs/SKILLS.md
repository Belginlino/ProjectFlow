# Skills and Competencies

Skills are evidence-backed learning outcomes, not self-declared badges only.

## Categories
### Technical
Programming, databases, APIs, testing, cloud, AI/ML, DevOps, security.

### Product
Requirements, problem solving, system design, UX, documentation.

### Professional
Teamwork, communication, leadership, time management, presentation.

## Skill structure
Skill → Level → Evidence → Projects → Evaluation → Reflection

## Verification
Self-declared → Evidence submitted → Mentor/Evaluator review → Verified evidence

Suggested levels:
- Introduced
- Developing
- Proficient
- Advanced

Do not assign a high skill level solely from activity count.

Avoid public leaderboards.
