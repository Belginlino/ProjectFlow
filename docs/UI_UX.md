# UI/UX Specification

## Navigation
Dashboard, Projects, My Work, Evidence, Reviews, Contribution, Evaluation, Outcomes, Settings.

## Project dashboard
Show status, milestones, requirements, evidence completeness, pending reviews, change requests and health alerts.

## Task board
Backlog → To Do → In Progress → Review → Testing → Done.

Every task shows requirement, assignee, due date, evidence and dependencies.

## Evidence Drawer
Preview, source, owner, linked entities, reviews, verification and history.

## Mentor Inbox
Project, issue, evidence, action required and deadline. Primary actions: Verify, Request Change, Comment.

## Health
Every alert shows severity, reason, evidence and action.

## Evaluation
Criterion → score → Why this score? → supporting evidence → evaluator comment.

## UX rule
Every automated/AI insight must expose:
1. reason
2. evidence
3. action
