# ProjectFlow — Development Documentation

ProjectFlow is an evidence-centered academic project intelligence platform.

## Core idea
Existing project-management tools manage tasks, workflows, milestones and reports. ProjectFlow adds an academic evidence layer connecting:

**Requirement → Task → Work → Evidence → Review → Feedback → Revision → Contribution → Evaluation → Learning Outcome**

## Core differentiators
1. Project Evidence Graph
2. Evidence-backed contribution verification
3. Feedback → Change Request → Revision → Verification
4. Explainable project-health alerts
5. Evidence-backed evaluation with “Why this score?”
6. Evidence-grounded viva
7. Configurable CO/PO/PSO mapping
