# Contribution Verification

## Objective
Assess individual contribution through multiple evidence sources.

## Sources
1. Verified task completion
2. Code/artifacts
3. Reviews performed
4. Technical decisions
5. Mentor observation
6. Reflection
7. Viva

## Do not
- use commit count as contribution
- use task count as contribution
- create public leaderboards
- reward meaningless activity
- automatically assign final marks

## Contribution view
Show a person's evidence timeline and verification state rather than one opaque productivity number.

## Verification
Unverified → Submitted → Mentor verified → Evaluator verified

Contribution assessment remains human-reviewable.
