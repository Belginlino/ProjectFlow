# Implementation Plan

## Phase 0 — Foundation
Repository, CI, environments, migrations, auth, roles and design system.

## Phase 1 — Core project management
Projects, teams, requirements, milestones, tasks and dependencies.

## Phase 2 — Evidence engine
Evidence upload, metadata, links, verification and timeline.

## Phase 3 — Mentor workflow
Inbox, review, comments, change requests, revisions and verification.

## Phase 4 — Contribution
Evidence timeline, artifacts, mentor observation, reflection and viva evidence.

## Phase 5 — Evaluation
Rubrics, criteria, scoring and Why-this-score.

## Phase 6 — Health
Deterministic rules for overdue work, blocked dependencies, missing evidence, missing tests and stale reviews.

## Phase 7 — AI
Feedback-to-change-request, evidence-grounded viva and grounded summaries.

## Phase 8 — Outcomes
Skills and configurable CO/PO/PSO mapping.

## Phase 9 — Polish
Accessibility, responsive UI, security, demo data, performance and error states.

## Team split
Frontend: screens/components/forms/graph UI.
Backend: APIs/auth/database/rules.
Integration: GitHub/storage.
AI: retrieval/prompts/grounding/evaluation.
QA: functional/accessibility/security/demo.
