# Accessibility

Target WCAG 2.2 AA principles where practical.

## Requirements
- Keyboard-accessible controls and visible focus.
- Logical tab order and no keyboard traps.
- Semantic HTML and correct heading hierarchy.
- Accessible names for icons and controls.
- Form labels and understandable errors.
- Never communicate status through color alone.
- Sufficient contrast.
- Upload progress and errors announced.
- Text alternatives for important charts.
- Responsive desktop/tablet/mobile layouts.
- Respect `prefers-reduced-motion`.
- Use consistent navigation and plain language.

## Acceptance checklist
- [ ] Keyboard-only navigation
- [ ] Visible focus
- [ ] Labeled forms
- [ ] Understandable errors
- [ ] Non-color status indicators
- [ ] Screen-reader labels
- [ ] Text alternatives for charts
- [ ] Accessible upload workflow
- [ ] Responsive UI
